Problem Statement

 

Business Context

 
The healthcare industry is rapidly evolving, with professionals facing increasing challenges in managing vast volumes of medical data while delivering accurate and timely diagnoses. The need for quick access to comprehensive, reliable, and up-to-date medical knowledge is critical for improving patient outcomes and ensuring informed decision-making in a fast-paced environment.

Healthcare professionals often encounter information overload, struggling to sift through extensive research and data to create accurate diagnoses and treatment plans. This challenge is amplified by the need for efficiency, particularly in emergencies, where time-sensitive decisions are vital. Furthermore, access to trusted, current medical information from renowned manuals and research papers is essential for maintaining high standards of care.

To address these challenges, healthcare centers can focus on integrating systems that streamline access to medical knowledge, provide tools to support quick decision-making, and enhance efficiency. Leveraging centralized knowledge platforms and ensuring healthcare providers have continuous access to reliable resources can significantly improve patient care and operational effectiveness.
 
Common Questions to Answer

1. Diagnostic Assistance: "What are the common symptoms and treatments for pulmonary embolism?"

2. Drug Information: "Can you provide the trade names of medications used for treating hypertension?"

3. Treatment Plans: "What are the first-line options and alternatives for managing rheumatoid arthritis?"

4. Specialty Knowledge: "What are the diagnostic steps for suspected endocrine disorders?"

5. Critical Care Protocols: "What is the protocol for managing sepsis in a critical care unit?"
 

Objective

 
As an AI specialist, your task is to develop a RAG-based AI solution using renowned medical manuals to address healthcare challenges. The objective is to understand issues like information overload, apply AI techniques to streamline decision-making, analyze its impact on diagnostics and patient outcomes, evaluate its potential to standardize care practices, and create a functional prototype demonstrating its feasibility and effectiveness.
 

Data Description

 
The Merck Manuals are medical references published by the American pharmaceutical company Merck & Co., that cover a wide range of medical topics, including disorders, tests, diagnoses, and drugs. The manuals have been published since 1899, when Merck & Co. was still a subsidiary of the German company Merck.

The manual is provided as a PDF with over 4,000 pages divided into 23 sections.

def clean_text(text):
    """
    Cleans repeated watermark/personal-use text and extra whitespace.
    This keeps the medical content but removes noisy repeated lines.
    """
    unwanted_phrases = [
        "This file is meant for personal use",
        "Sharing or publishing the contents",
        "liable for legal action"
    ]

    lines = text.split("\n")
    cleaned_lines = []

    for line in lines:
        line = line.strip()

        # Remove empty lines
        if not line:
            continue

        # Remove repeated watermark/personal-use lines
        if any(phrase in line for phrase in unwanted_phrases):
            continue

        cleaned_lines.append(line)

    return "\n".join(cleaned_lines)

def generate_rag_response(
    user_input,
    k=3,
    max_tokens=700,
    temperature=0,
    top_p=0.95,
    top_k=50
):
    """
    Generates a RAG-based answer by:
    1. Retrieving relevant chunks from the vector database
    2. Creating a context from retrieved chunks
    3. Passing context + question to the LLM
    4. Returning the generated answer
    """

    global qna_system_message, qna_user_message_template, vectordb, llm

    try:
        # Create retriever dynamically so k can be tuned during experiments
        current_retriever = vectordb.as_retriever(
            search_type="similarity",
            search_kwargs={"k": k}
        )

        # Retrieve relevant document chunks
        relevant_document_chunks = current_retriever.get_relevant_documents(user_input)

        # Prepare context with page numbers
        context_list = []
        source_pages = []

        for i, doc in enumerate(relevant_document_chunks, start=1):
            page_number = doc.metadata.get("page", "Unknown")

            # PyMuPDF page index starts from 0, so add 1 for human-readable page number
            if isinstance(page_number, int):
                display_page = page_number + 1
            else:
                display_page = page_number

            source_pages.append(display_page)

            context_list.append(
                f"Source chunk {i} | Page: {display_page}\n{doc.page_content}"
            )

        context_for_query = "\n\n".join(context_list)

        # Build user message
        user_message = qna_user_message_template.format(
            context=context_for_query,
            question=user_input
        )

        # Final Mistral-style prompt
        prompt = f"""[INST]
{qna_system_message}

{user_message}
[/INST]"""

        # Generate response
        model_output = llm(
            prompt=prompt,
            max_tokens=max_tokens,
            temperature=temperature,
            top_p=top_p,
            top_k=top_k,
            stop=["</s>"]
        )

        answer = model_output["choices"][0]["text"].strip()

        return answer

    except Exception as e:
        return f"Sorry, I encountered the following error:\n{e}"

def generate_ground_relevance_response(
    user_input,
    k=3,
    max_tokens=700,
    eval_max_tokens=350,
    temperature=0,
    top_p=0.95,
    top_k=50
):
    global qna_system_message, qna_user_message_template
    global groundedness_rater_system_message, relevance_rater_system_message
    global user_message_template, vectordb, llm

    # Create retriever with the selected k value
    current_retriever = vectordb.as_retriever(
        search_type="similarity",
        search_kwargs={"k": k}
    )

    # Retrieve relevant document chunks
    try:
        relevant_document_chunks = current_retriever.get_relevant_documents(user_input)
    except AttributeError:
        relevant_document_chunks = current_retriever.invoke(user_input)

    # Prepare retrieved context with source/page information
    context_list = []

    for i, doc in enumerate(relevant_document_chunks, start=1):
        page_number = doc.metadata.get("page", "Unknown")

        if isinstance(page_number, int):
            display_page = page_number + 1
        else:
            display_page = page_number

        context_list.append(
            f"Source chunk {i} | Page: {display_page}\n{doc.page_content}"
        )

    context_for_query = "\n\n".join(context_list)

    # Generate RAG answer using the same RAG function from the previous section
    answer = generate_rag_response(
        user_input=user_input,
        k=k,
        max_tokens=max_tokens,
        temperature=temperature,
        top_p=top_p,
        top_k=top_k
    )

    # Prepare judge input
    judge_user_message = user_message_template.format(
        context=context_for_query,
        question=user_input,
        answer=answer
    )

    groundedness_prompt = f"""[INST]
{groundedness_rater_system_message}

{judge_user_message}
[/INST]"""

    relevance_prompt = f"""[INST]
{relevance_rater_system_message}

{judge_user_message}
[/INST]"""

    # Groundedness evaluation
    groundedness_response = llm(
        prompt=groundedness_prompt,
        max_tokens=eval_max_tokens,
        temperature=0.0,
        top_p=0.95,
        top_k=50,
        stop=["</s>"]
    )

    # Relevance evaluation
    relevance_response = llm(
        prompt=relevance_prompt,
        max_tokens=eval_max_tokens,
        temperature=0.0,
        top_p=0.95,
        top_k=50,
        stop=["</s>"]
    )

    groundedness_output = groundedness_response["choices"][0]["text"].strip()
    relevance_output = relevance_response["choices"][0]["text"].strip()

    return answer, groundedness_output, relevance_output
